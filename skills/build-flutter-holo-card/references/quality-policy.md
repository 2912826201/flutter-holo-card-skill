# 按素材评分，达标即用

先做格式检查，再在目标显示宽度（未知时 300 逻辑像素）看整体与主要细节。只有怀疑主体缺失或严重错位时才放大定位；不要逐像素找瑕疵。质量分由看过图片的执行者给出，脚本只算加权分，不能从边缘命中率推导视觉质量。

## 评分表

每项维度为 0–100 的实数。量表锚点：100 无明显问题；90 轻微局部偏差；80 可直接使用但有小瑕疵；70 有明显局部问题；50 大范围问题；0 缺失。给每种素材写一句具体观察，避免机械地全部打满分。

| 类型 / 通过线 | 维度与权重 | 可以接受 | 应停止放行的内容缺陷 |
|---|---|---|---|
| foreground / 85 | 主体和面板完整 `completeness` 40%；位置比例 `placement` 35%；边缘 `edges` 25% | 少量发丝遗漏、细框局部误差、小范围多保留背景、Alpha 柔边；文字按整块面板保留 | 主要人物/手/武器或整块信息区缺失，大幅缩放位移，正常尺寸出现大洞 |
| background / 80 | 风格色调 `style` 30%；移除前景 `removal` 40%；连续性及延展 `continuity` 30% | 被遮挡区域的新云朵/纹理，与原图不逐像素一致；轻微色差和局部纹理变化 | 清楚可识别的残留人物/大块文字，明显占位块或断层，露出空白边 |
| lineart / 75 | 主要对象可识别 `structure` 35%；整体位置 `placement` 35%；背景及文字区干净 `cleanliness` 30% | 省略细碎装饰/发丝/小字，线条轻微偏移，素描笔触、少量孤立杂线；不要求完整复刻 | 主要主体整体错位，大面积背景描线，大片填实使光效洗白 |
| composite / 80 | 文字主体可读 `readability` 40%；图层关系 `layering` 35%；整体观感 `appearance` 25% | 不影响读取和观看的局部细节偏差 | 正常显示时文字不可读、主体断裂/重影、严重错位或渲染失效 |

通过需要每种必需素材各自达到通过线、没有阻断项；不能用背景高分抵消前景失败。刚好达到阈值就通过。边缘命中比例、覆盖率、透明边距离只能作为定位线索，不能自动上升为阻断项。少量瑕疵不能因“可察觉”三个字就被否决；应依照表中对可用性的影响扣分。

格式硬条件仅包括：文件可读、输入与证据未过期、运行时画布/模式正确、前景有实际透明度、背景不透明、素描有可用线条、原图 RGB/文字数据被保留。生成图尺寸不同可一次整画布缩放（宽高比偏差 ≤3%）；不裁切、不局部变形。素描覆盖率偏高/偏低只警告，空图或几乎全实心才阻断。

## 评分记录

`review-mask --quality FILE` 用只含 foreground 的 JSON；`review --quality FILE` 使用该档的完整记录。height 需要四类，medium 需要 lineart/composite，low 只需 composite。例如 medium：

```json
{
  "lineart": {
    "scores": {"structure": 80, "placement": 78, "cleanliness": 85},
    "blockers": [],
    "notes": "主要人物和武器位置吻合，省略了小装饰，背景干净。",
    "attempts": 1
  },
  "composite": {
    "scores": {"readability": 95, "layering": 85, "appearance": 85},
    "blockers": [],
    "notes": "300 宽叠加预览文字清楚，轮廓集中在主体；未验证 GPU 动态渲染。",
    "attempts": 1
  }
}
```

`attempts` 记录该素材实际生图调用次数（1 或 2）；composite 是检查次数，可为 1 或 2，不代表额外生图。没有候选或格式失败直接记录失败原因，不为了填评分而虚构图片。证据参数必须指向已查看的当前图片/预览。评分计算结果与素材/证据一起绑定，`check` 会重新校验，不仅相信一条 pass 字符串。

## 有界修正

首轮合格即冻结。首轮不足时，仅定位最影响使用的一个问题，用原图和失败候选向生图能力发起一次针对性编辑；已经合格的其他素材不重做。两次都不合格保留得分更高的候选作为未通过的诊断结果，结束该项。技术错误同样占用请求预算，禁止藏在重试器里无限调用。明确拒绝即停止该请求；不能改写同一目的或切换算法继续完成被拒步骤。

不要因警告启动新一轮全套检查、搭建 Demo、训练分割器、手画蒙版或自动降档。脚本自身错误可以修复后重跑同一图片的格式检查，不消耗生图次数；修改评分标准以让失败结果过关不属于修复。
