# height：背景后退

生成透明前景、完整背景、前景素描各一张。三个任务直接引用原图即可；前景 Alpha 决定归属，前景运行时 RGB 来自原图。无需预先裁图或制作背景指引。

## 前景提示词模板

> 请分离参考卡图的前景，输出真正透明背景的 PNG。保持整张原画布的宽高比、构图、位置和对象大小，不缩小居中、不加安全边距、不裁切。保留 FOREGROUND_ELEMENTS（人物、装备、前景装饰及卡框）；文字、标题和规则区连同其原有面板底色作为完整区域保留，不逐字抠取。只移除 BACKGROUND_ELEMENTS。保持原遮挡关系及 EDGE_CONTACTS 的原始触边位置；主体和信息面板填实，允许自然抗锯齿柔边。不要输出画在图片里的棋盘格。

有实际 Alpha 时直接读取，不使用生成图 RGB 重写卡面。工具不支持透明输出时，可以在两次预算内让生图能力直接输出同构图的黑白归属蒙版（白色是上述保留对象，黑色是背景）；用 `prepare_foreground.py --generated-kind mask` 读取。蒙版仍由生图完成，不能本地推断分割。不要为了不影响观看的发丝、细框或小孔反复重生图。

## 背景提示词模板

> 根据参考卡图绘制完整背景。移除 FOREGROUND_ELEMENTS 及全部文字、信息面板、卡框、前景特效，在这些区域自然补全 BACKGROUND_ELEMENTS。延续原图背景的色调、光照、透视和大体布局，允许对原来被遮挡处创作新的合理纹理。向四周各延展约 8%，原卡画面位于扩展画布中央；输出整幅不透明画面，无人物残影、框字、卡片边界、占位色或空白边。保持竖横比例，目标 EXTENDED_W×EXTENDED_H 或工具支持的最近比例。

直接使用生图的完整背景，不把原背景像素硬贴回去制造拼接缝。随包 shader 用背景移动前后的差值作用于原图，中立位置仍显示原图，因此不需要逼迫背景像素级复刻。背景只按风格、移除干净程度、连续性及延展评分。

素描使用[资源流程中的共用提示词](resource-workflow.md#前景素描提示词)。通过线为前景 85、背景 80、素描 75，按[质量评分](quality-policy.md)处理。

## 组合检查

asset-only 看原图、Alpha 叠加、完整背景、轮廓叠加，确认资源数为 5，记录未验证动态渲染。完整集成再检查中立及四个代表倾斜方向：前景/文字固定、背景后退、无明显露边或主体破裂。发现可疑问题才增加极限姿态；不对每张素材重复执行完整 GPU 矩阵。景深范围 0–3，0 关闭视差，不采用负景深。
